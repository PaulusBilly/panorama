# DM Sans

Source: Google Fonts `ofl/dmsans/DMSans[opsz,wght].ttf` at commit `5b35b7208dd4100571326fdf37f030b32a524232`.

The bundled static weights 400, 500 and 700 were generated at optical size 14 with FontTools 4.63.0 and encoded as TTF for desktop subtitles and WOFF2 for the web. The medium face uses the desktop family name `DM Sans Medium`. Copyright and redistribution terms are in [OFL.txt](OFL.txt).
